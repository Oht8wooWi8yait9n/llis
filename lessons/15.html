NASA Lesson #0015: Torque Requirements Aligned to Fitting Sizes

Lesson ID: #0015 (Database ID: 15)
Date: 1993-07-23
Organization: Johnson Space Center
Program Phase: None
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

Hydraulic fluid leakage was noted at the interface of the flex hose and Rosan fitting on a hydraulic pump. The fittings were a different size at each end of the flex hose. Different size fittings require different torque values, which the specifications did not identify. The hydraulic system is inspected prior to each mission of the shuttle vehicle. Review of the procedure used during installation of the hydraulic system shows that one end of the flex hose was torqued to 120 foot pounds. The installation drawing does not specify that the other end of the flex hose has a smaller fitting that should require a lower torque. Leakage was corrected by a hose replaced and torqued properly.

Lesson(s) Learned

Failure to call out proper torque requirements for fittings with different sizes caused a hydraulic leak in a critical orbiter system.

Recommendation(s)

Inspections are performed prior to flight to check the flex hose connections for proper torquing and for the absence of leaks.
