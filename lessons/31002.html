NASA Lesson #31002: SharePoint Nintex Licensing

Lesson ID: #31002 (Database ID: 31002)
Date: 2022-03-15
Organization: Kennedy Space Center
Program Phase: Evaluation
Topic / Category: Integration and Testing, Program Management, Systems Engineering and Analysis, Administration / Organization, Communication Systems, Information Technology / Systems, Configuration Change Control
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

KSC recently upgraded from SharePoint 2016 (a web-based collaboration platform) to SharePoint 2019.  A third party tool, Nintex Workflow used to automate business processes in SharePoint, only allowed for a 30 day migration license.  All SharePoint sites were migrated in time.  However, the migration license was not updated to the production license.  When the migration license ran out, users were not able to use Nintex workflow or forms.

Lesson(s) Learned

We learned that we need to improve our communication for license upgrades and plan the steps involved.  It took almost 6 hours for the new licenses to be acquired.

Recommendation(s)

Corrective Action Plan:

  • Improve our communication with vendors to ensure we have a thorough understanding of the license upgrade steps.
  • Add a lessons learned to the SharePoint 2019 Upgrade Project and to the Knowledge Management Articles webpage for future reference.
  • Scheduled a quarterly review of SharePoint licensing so the team and the NASA point of contact are aware of upcoming expirations.

Evidence / Additional Context

License mangement for third party tools has been given a higher priority on the upgrade checklists and knowledge articles have been created for future reference.
