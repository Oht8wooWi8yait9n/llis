NASA Lesson #3616: Management Reserve

Lesson ID: #3616 (Database ID: 3616)
Date: 2010-08-26
Organization: Marshall Space Flight Center
Program Phase: Formulation &raquo; Phase B
Mission Directorate: Aeronautics Research, Human Exploration and Operations, Science
Topic / Category: Program Management, Program planning / development and management
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

The CxP provided direction that there would be no MR maintained by their projects. This direction contradicted the CxP Earned Value Management (EVM) System Description definition and use of MR by the CxP Projects. The CxP maintained reserves at the Program level, requiring Projects to request additional budget for any changes within scope to the Project but out of scope to the Project Control Accounts. In reality, CxP maintained a funding reserve, not a budget reserve. The direction to not allocate/show MR is contradictory to project management best practices and directly violates the guidelines of the ANSI/EIA-748 Earned Value Management Systems.

Lesson(s) Learned

All projects have some element of risk and should identify a MR contingency account for unplanned activity within the project scope. Unanticipated control account scope such as changes in rates, or changes in schedule are circumstances representative of situations that may result in the determination that budgets assigned to a Project Control Account Manager (P-CAM) are inadequate (i.e., in scope to the project but out of scope to the control accounts). The only ANSI/EIA-748 compliant course of action is for the project manager to establish and maintain MR outside the Performance Measurement Baseline (PMB) to provide budget for unknown-unknowns, or known-unknowns. This not only complies with the ANSI/EIA-748 guidelines, but is also a project management best practice.

Recommendation(s)

  1. Ensure Agency EVM System Description Document and best practices clearly define MR and Undistributed Budget (UB) to include their uses.
  2. Emphasize intent of ANSI/EIA-748 guidelines in training and communication plan.
  3. Train necessary personnel on the difference between project budget management reserve, Unallocated Future Expenses, and funding reserves.
  4. Allow projects to budget for and report MR to manage project risks and to comply with the ANSI/EIA-748.

Evidence / Additional Context

The project budget logs accurately reflect the budget traceability for all budgets inclusive of MR and agree with the authorized Project Budget Base. Project EVM reports and information reflect MR trends and explain uses (to/from accounts).

Related Policies & Standards

For additional information, review ANSI/EIA-748, Earned Value Management Systems and CxP 70070-ANX09, Constellation Program, Program Management Plan, Annex 9: Earned Value Management System Description, Rev A, 11/4/09 sections 4.0 and 4.2.2.1.
