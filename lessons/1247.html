NASA Lesson #1247: International Space Station/Caution and Warning Alerts/Inhibits

Lesson ID: #1247 (Database ID: 1247)
Date: 2002-06-17
Organization: NASA Headquarters
Program Phase: None
Mission Directorate: Human Exploration and Operations
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

Lack of visual or aural warning that caution and warning functions have been inhibited.

Lesson(s) Learned

There is no visual or aural indication to the Crew that safety-related alerts have been inhibited.

Recommendation(s)

Develop an appropriate alerting system to remind the crew that Caution & Warning functions have been inhibited and/or to enable the crew to limit the inhibit to only a specific period. Avoid the need to inhibit C&W alerts by countering the root causes of false alarms whenever possible.

Evidence / Additional Context

The C&W SIT will address this condition and bring recommendations forward to the Program for disposition.
The Caution and Warning System Integration Team (CWSIT) considers eliminating false alarms as a primary objective for planned Caution and Warning System improvements.
