NASA Lesson #1438: Accident Investigations/Background Information

Lesson ID: #1438 (Database ID: 1438)
Date: 2003-08-31
Organization: Johnson Space Center
Program Phase: None
Mission Directorate: Human Exploration and Operations
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

Some Columbia Accident Investigation Board (CAIB) members arrived with minimal knowledge of Space Shuttle systems. Subsequently, the action/request for information system was flooded with informational and data requests to come up to speed, slowing down the NASA technical investigation/analysis.

Lesson(s) Learned

NASA needs to be better prepared to handle the independent investigators in terms of technical and procedural materials that will increase the learning curve of Board members.

Recommendation(s)

  • Anticipate and prepare for an educational process for an independent accident investigation board. Readily available data such as drawing databases and existing websites that an independent Board can have immediate access to should be kept up-to-date and more user friendly.
  • Create a directory or cheat sheet with pointers to existing databases, websites, etc. NASA contingency planning should maintain basic documentation procedures that will always be scrutinized in a major investigation (e.g. maintenance, facilities, safety programs, contracts, training).
  • Improve archival system to provide the most rapid possible recovery and delivery of documentation that shows vehicle histories, problems, etc.
  • Assign this background function to NASA's on-site library system or to the flight program offices.
