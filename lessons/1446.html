NASA Lesson #1446: Accident Investigations/Database/Collaborative Tool PBMA (Process Based Mission Assurance)

Lesson ID: #1446 (Database ID: 1446)
Date: 2003-08-31
Organization: Johnson Space Center
Program Phase: None
Mission Directorate: Human Exploration and Operations
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

For the Columbia accident investigation, the PBMA tool was oversold to rapidly assembled Board and Task Force members and did not deliver capabilities as expected. For example, record keeping, cataloging, tracking/status, search & retrieval, and metrics data were not immediately available in PBMA, resulting in an overall frustration and delays with the capability for getting data out of PBMA into the hands of the users. This tool was often found to be incompatible with other tools and its security system was overly complex.

Lesson(s) Learned

For large accident investigation support, is unlikely that you can select a software system for action item tracking and configuration management of investigative data that will make everyone happy at the same time.

Recommendation(s)

Consider the following criteria when selecting a software management system for accident investigation support:

  • allows for the easy upload and download of very large files 100 to 300MB.
  • is flexible and compatible enough to adapt to new requirements
  • the advantages and disadvantages are sufficiently vetted by the Board
  • the system can be adequately tested in the Board's environment before full buy-in
  • is not overly complex, so that investigators don't have to spend many hours training
  • remote access consistent with the Board's organization and nothing more
  • factor of security is consistent with investigations need for simplicity and rapid startup
  • has good keyword search capability
  • avoid systems that will immediately require customization
  • use a Commercial Off the Shelf (COTS) solution when possible
  • electronic tools must be able to store and manipulate 3-D engineering models.
