NASA Lesson #1269: Website as a Communications Tool

Lesson ID: #1269 (Database ID: 1269)
Date: 2002-01-15
Organization: Kennedy Space Center
Program Phase: None
Mission Directorate: Human Exploration and Operations
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

The Website structure for the program use today is good however, communicating its existence and accessibility is key for the program visibility. The website can continue to help and serve potential and existing customers effectively at every phase of a project, study or proposal development. In addition it can help our customers stay informed while the program keeps focus on overall communications. Our post and pre-communications efforts and website accessibility insures that we are meeting the customer's needs. The program is a vital partner in defining and communicating to our customers the goals of the program. The website should be used to help customers understand and articulate our program initiatives as a method to funnel their proposals. This will inherently create opportunities and a roadmap for the program.

Lesson(s) Learned

Website existence needs to be made aware and available to a broader customer base. Communicate the availability of the website and program initiatives through other means.

Recommendation(s)

Identify to the customer base that the website exist and consider other communication tools such as bulletins (NASA Centers). Communication tools such as the website and other sources often promise tremendous benefits such as increase customers and program awareness. Review every six months on how to improve the website and provide additional tools to communicate program initiatives. Continue to provide the customers with the access to the website and insure that communicating the program goals is a priority.
