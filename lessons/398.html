NASA Lesson #0398: Galileo Command and Data Subsystem (CDS) Marginal Power Supply Voltages

Lesson ID: #0398 (Database ID: 398)
Date: 1995-06-07
Organization: Jet Propulsion Laboratory
Program Phase: None
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

Following rework of the Galileo Spin Bearing Assembly (SBA), tests were conducted at the system level to assure that the changes made in the SBA did not affect spacecraft operation. Results of the tests showed lower than expected CDS voltages on the despun side of the CDS. These low voltages were isolated to the trace size of the printed wiring board conductors within the main CDS power supply. The problem was corrected by adding conductors in parallel with the power supply printed wiring board traces.

Reference(s): PFR #44928

Lesson(s) Learned

The trace size of subsystem printed wiring board conductors can affect system level voltages.

Recommendation(s)

  1. Subsystem design analysis must not only include the circuit design, but all aspects of the end-to-end implementation, including such things as current carrying capacity of printed wiring board conductors.
  2. Testing at the subsystem level must include realistic duplication of the flight system configuration that could affect subsystem performance, including consideration for worst case system conditions.

Evidence / Additional Context


JPL has referenced the lesson as supporting Paragraph 4.3.3.2 ("Power/Pyrotechnics Design: Power Generation - Power Demands") in the JPL standard "Design, Verification/Validation and Operations Principles for Flight Systems (Design Principles)," JPL Document D-17868, Rev. 3, December 11, 2006.
