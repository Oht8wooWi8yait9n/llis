NASA Lesson #0447: Component Anomalies Log - Scout Program

Lesson ID: #0447 (Database ID: 447)
Date: 1995-06-12
Organization: Glenn Research Center
Program Phase: None
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

At the Loral Vought Systems in Dallas, Texas prior logbook test data history was evaluated as part of a normal failure investigation. During this review a trend in data was sometimes observed that indicated a prior drift or shift towards an out-of-tolerance condition.

The Scout Program initiated a test data monitoring program on selected assemblies. Design, quality and/or reliability engineers reviewed the test data after each retest on the assembly or vehicle level. The appropriate engineer maintained supplementary notes. The list of assemblies to be monitored grew as additional parameters were identified.

Typical parameters monitored were:

  1. Spin-up time, mass unbalance and null voltages on gyros
  2. Receiver and transmitter frequencies on beacon transponders
  3. Output frequencies of voltage controlled oscillators
  4. Resistance measurements on relay assemblies
  5. Discharge times at constant current on rechargeable batteries
  6. De-spin time on bearings

This practice has been in place since the beginning of the Scout Program in 1960.

Lesson(s) Learned

Components may have anomalies that are within specification and which later become the source of other problems.

Recommendation(s)

Responsible system engineers should maintain a log for all components, which have anomalies that are within specification.

Evidence / Additional Context

Because of this monitoring, many failures were prevented by rejecting the identified assembly prior to flight failure or by the early detection of potential out-of-tolerance parameters. This evaluation of test data resulted in attaining a higher reliability of flight performance and prevented costly component replacement in the field.
