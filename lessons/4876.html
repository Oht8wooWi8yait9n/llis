NASA Lesson #4876: Operational Supportability Requirements

Lesson ID: #4876 (Database ID: 4876)
Date: 2011-01-03
Organization: Kennedy Space Center
Program Phase: Approval
Mission Directorate: Human Exploration and Operations
Topic / Category: Logistics, Ground support systems, Configuration control and data management
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

Common data items are necessary to set up a logistics infrastructure that will be used to evaluate hardware. For the Constellation Program, the Orion and Ares Projects developed these tools independently from the Ground Operations Project, and they produced final products that were very different. SMR code charts and Logistic Control Numbers (LCNs) are examples of data formats that need to be identified. The SMR codes and LCNs are used not only for the Logistics Support Analyses, but also in determining operational requirements and in integrating the support, reliability, maintainability, safety, and disposal functions of the overall program.

Lesson(s) Learned

Commonality in logistics data items such as SMR code charts is necessary to easily transfer parts across projects.

Recommendation(s)

Identify essential data items that need to be part of a common logistics infrastructure across projects, and specify those data items in a Level II requirements document.
