NASA Lesson #1452: Accident Investigations/Configuration Management (CM)/Personnel Issues

Lesson ID: #1452 (Database ID: 1452)
Date: 2003-08-31
Organization: Johnson Space Center
Program Phase: None
Mission Directorate: Human Exploration and Operations
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

For the Columbia accident investigation, personnel and processes were not in place to assist in startup. Although heroic efforts on the part of key CM personnel minimized the number of individual problems, better planning might have improved startup efficiency.

Lesson(s) Learned

Have a set of draft processes ready to implement for data management and configuration management.

Recommendation(s)

  • Include CM processes defined for the Task Force as an initial reference in the NASA Contingency Action Plan (CAP). Revising a previous or pre-established process will be easier than starting from scratch and the Board will run more smoothly as well.
  • Ensure that adequate CM personnel resources are available at startup.
  • Use these guidelines for CM personnel requirements (EPs):
    • (1) Action Trackers (Start-up: 4, Peak: 8, Std Ops: 4)
    • (2) Data Entry and Librarian/Archivist: 5, Library function includes expertise on scanning and archiving. Bring in someone familiar with library science to assist with the document management function. Create a library group.
    • (3) IT Support/Processes (Start-up: 3 Database Administrators: 2 (Prime/Back-up): Individual should have knowledge of existing NASA action tracking AND document management databases
    • (4) Meeting Coordinator/Minute Recorder: 3
