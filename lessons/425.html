NASA Lesson #0425: Voyager Impact of Real-Time Commanding on Flight Operations (~1977)

Lesson ID: #0425 (Database ID: 425)
Date: 1996-07-10
Organization: Jet Propulsion Laboratory
Program Phase: None
Source: View Official NASA LLIS Entry (live system)

Driving Event / Description

(Relevant Historical Lesson(s) Learned)

The Voyager spacecraft system, Ground Data System (GDS) and Mission Operations System (MOS) were designed to accommodate very limited real-time commanding. Early flight experience revealed that frequent real-time commanding was necessary to support mission objectives. The required modification to the GDS and MOS was difficult and these systems still retain limiting characteristics which make real-time command generation more difficult and costly than is desirable.

Lesson(s) Learned

Careful determination of real-time commanding requirements must be made early in mission design.

Recommendation(s)

  1. The spacecraft design should consider the ease of commandability of those subsystems most likely to require real-time commanding.
  2. Ground Software must be designed to readily accommodate the generation of the necessary real-time commands and to minimize the time and effort required to update the software initial conditions resulting from real-time command activity.
  3. MOS procedures must accommodate real-time commanding in a way which meets established timeliness criteria and is compatible with acceptable levels of risk.
  4. The resulting capabilities and limitations must be widely communicated to all Project interests.

Evidence / Additional Context


JPL has referenced the lesson as supporting Paragraph 4.5.1.4 ("Telecommunications System Design: General - Telecommunications Capability for Special Mission Events") in the JPL standard "Design, Verification/Validation and Operations Principles for Flight Systems (Design Principles)," JPL Document D-17868, Rev. 3, December 11, 2006.
